How it was built

  1. 00_dataset_setup — scan data/raw, drop byte-identical duplicates, stratified 70/15/15 split (seed 42).
  2. 01_custom_cnn — from-scratch CNN, Adam, augmentation, early stopping.
  3. 02_transfer_learning — MobileNetV2, Rescaling(2.0, offset=-1.0) to [-1,1], frozen base then fine-tune.
  4. 03_comparison — shared eval_utils artifacts, comparison table, McNemar test.
